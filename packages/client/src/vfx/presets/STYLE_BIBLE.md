## Family Style Bible (Abilities Mode)

### Frontline Bulwark (BULWARK / URSHARI)
- **Palette:** steel-blue + amber impact accents.
- **Shape language:** arcs, rings, heavy chunks.
- **Motion:** stable shield walls, heavy impulse pops, short recoil.
- **Abilities:**
  - `SEISMIC_SLAM` uses chunked shock-dust impact.
  - `IRON_FORTRESS` uses a **directional 180-degree half-shield** loop + block-arc flashes.

### Sky Hunter (AERIAL / NEXARIM)
- **Palette:** clean cyan wind + hot orange-white orbital fire.
- **Shape language:** ribbons and needle shards.
- **Motion:** high-speed, low-drag, directional readability.
- **Abilities:**
  - `GALE_FORCE` stays premium ribbon-forward.
  - `SKY_FIRE_STRIKE` is telegraph ring -> beam strike -> **thermite-like rain** spread in strike radius.

### Venom Shadow (SERPENTINE / VIRDIS)
- **Palette:** toxic green and arcane violet.
- **Shape language:** wisps, cursed rings.
- **Motion:** swirl/noise with eerie persistence.
- **Abilities:**
  - `SHADOW_LEAP` trail uses mesh wisps + turbulence.
  - `BASILISK_GAZE` pulse ring with neon curse tones.

### Scrap Tech (SCAVENGER / PROTOAN)
- **Palette:** electric cyan with hard specular energy.
- **Shape language:** shards, spirals, trails.
- **Motion:** magnetic orbit, pull lines, jagged acceleration.
- **Abilities:**
  - `SCRAP_MAGNET` well uses orbital trail spirals.
  - token pull uses bright shard pull streaks.

### Charger Herd
- **Palette:** hot gold/orange.
- **Shape language:** speed lines, impact shards, aura rings.
- **Motion:** aggressive forward bursts and rhythmic stomp puffs.
- **Abilities:**
  - `BATTERING_RAM` trail + heavy impact burst.
  - `UNSTOPPABLE_HERD` ally aura + locomotion dust.
